## Calculator

Модуль calculator предназначен для вычисления арифметических выражений.

Поддерживаются следующие операции:

- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — деление;
- `//` — целочисленное деление;
- `%` — остаток от деления;
- `**` — возведение в степень;
- `()` — круглые скобки.

Для разбора арифметического выражения используется алгоритм рекурсивного спуска.


## Converter

Модуль converter предназначен для перевода величин между различными единицами измерения.

Поддерживаются следующие категории:

### Расстояние
- `mm` — миллиметры;
- `cm` — сантиметры;
- `m` — метры;
- `km` — километры.

### Масса
- `g` — граммы;
- `kg` — килограммы.

### Температура
- `c` — градусы Цельсия;
- `f` — градусы Фаренгейта;
- `k` — Кельвины.

## Запуск

для этого надо перейти в папку src
```bash
cd src
```

### чтобы использовать калькулятор, нужно ввести следующую команду:
```bash
python -m toolkit calc "EXPRESSION"
```
пример:
```bash
python -m toolkit calc "4 * (4 + 2)"
```

### чтобы использовать конвертор, нужно ввести следующую команду:
```bash
python -m toolkit convert VALUE --from UNIT --to UNIT
```
пример:
```bash
python -m toolkit convert 5 --from km --to m
```

### есть функция help:
```bash
python -m toolkit --help
python -m toolkit calc --help
python -m toolkit convert --help
```
